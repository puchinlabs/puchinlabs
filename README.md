# Puchin Labs

[English](#english) · [简体中文](#简体中文)

## English

An independent lab for studying AI, building AI-native apps, and putting AI to work in everyday tasks.

### AI Research and Learning

I study language model fundamentals, embeddings and retrieval, and how agents plan and use tools. I test what I learn with small, reproducible experiments.

### AI-Native App Development

I prototype iOS and macOS apps in Swift and SwiftUI, exploring how model capabilities can shape core features and interactions.

### AI Workflows in Practice

I use AI to explore codebases, synthesize research, and automate recurring tasks. I turn useful approaches into reusable workflows with explicit checks for the results.

## 简体中文

Puchin Labs 是一个独立实验室，关注 AI 原理、AI Native 应用，以及如何把 AI 用在日常工作中。

### AI 研究学习

学习大语言模型原理、Embedding 与检索，以及 Agent 如何规划和调用工具，并用可复现的小实验验证理解。

### AI Native 应用开发

用 Swift 和 SwiftUI 构建 iOS 与 macOS 应用原型，探索如何把模型能力融入产品的核心功能与交互。

### AI 工作流实践

用 AI 探索代码库、整理研究资料和自动化重复任务，把有效做法整理成可复用的工作流，并明确如何验证输出。
